## Brains artwork

The Brains name, `brains.ai` visual wordmark, multipolar neuron mark, lockups, icons, and
social-preview artwork in this directory are original project artwork maintained by the
Brains contributors. Unless a separate notice is added by the maintainers, these files
are distributed under the repository's [MIT License](../LICENSE).

This notice records authorship and repository licensing only. It does not assert a
trademark registration or add a separate trademark license.

## Fonts

No font binaries, webfont files, `@font-face` sources, or remote font dependencies are
included in this brand kit. The editable SVGs and preview use generic system font families,
so there is no third-party font license bundled here.

Space Grotesk is a preferred display option only when a downstream consumer independently
provides and licenses it. It is not redistributed by this repository, so its license text
is not copied into this file.
